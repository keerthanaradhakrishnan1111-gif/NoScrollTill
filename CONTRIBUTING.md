# Contributing to NoScrollTill 💜

Thank you for your interest in contributing to NoScrollTill!

## How to Contribute

- **Report bugs:** Open an issue with steps to reproduce the problem.
- **Suggest features:** Explain your idea in a GitHub issue.
- **Fix issues:** Comment on an issue before starting work.

## Getting Started

1. Fork this repository.
2. Clone your fork and open the project in Android Studio.
3. Create a branch for your changes.
4. Make and test your changes.
5. Submit a pull request to the `main` branch.

## Guidelines

- Keep changes focused and code readable.
- Test your changes whenever possible.
- Do not commit passwords, tokens, private keys, or `local.properties`.
- Preserve existing functionality unless your change intentionally modifies it.
- Never request or store LeetCode passwords or session cookies.
